# 2042: Interceptor

A Java 2D arcade space shooter, inspired by the classic *1942*, built with the **StdDraw** graphics library and designed using **object-oriented programming (OOP)** principles.

## Highlights
- Rendering, animation, and keyboard input handled through StdDraw, with double buffering for smooth frames.
- Player-controlled interceptor spaceship battles 6 enemy ships across 3 lives.
- Bullet management, collision detection, and game state handled through array-based tracking.
- Written report included in `report/`.
